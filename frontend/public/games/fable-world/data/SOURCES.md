## What was adapted

- Level gates plus a spendable knowledge currency.
- Creature work suitability as a set of jobs with levels 1–4.
- Resource skill gates: basic stone first, ore/coal second, rare crystal third.
- Capture tools divided into recommended level bands.
- Dangerous climate biomes doubling as late-game resource regions.
- Base growth increasing worker capacity and encouraging specialization.

## What deliberately changed

- Five compact regions sized for short mobile sessions instead of a large 3D world.
- A single top-down real-time screen for exploration, combat, gathering, construction, and worker visualization.
- Original names, creatures, mythology, resources, regions, technologies, formulas, and progression targets.
- Smaller level cap and faster first automation for a Telegram WebApp MVP.

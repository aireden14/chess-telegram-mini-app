# archive

Код, который решено сохранить, но не публиковать.

Всё, что лежит здесь, намеренно вынесено за пределы `frontend/public/`, поэтому не
попадает ни в `vite build`, ни в деплой на Vercel. В git при этом остаётся — забрать
можно в любой момент.

## hexforge

Гексовая автоматизация, версии 2.0–2.1 (1 июля 2026). Standalone-билд на 59 МБ.

Из хаба игра исчезла давно: маршрута в `App.tsx` нет, в каталоге `GamePickerScreen.tsx`
её тоже нет — то есть открыть её было нельзя, а в каждую сборку фронта она всё равно
уезжала. 22 августа 2026 вынесена сюда.

Вернуть в строй:

```bash
git mv archive/hexforge frontend/public/games/hexforge
```

и добавить экран (`frontend/src/features/hexforge/HexForgeScreen.tsx` на месте), роут в
`App.tsx` и плитку в `ALL_APPS`.
